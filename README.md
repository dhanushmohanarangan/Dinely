# Dinely

A Meal Preference Management System built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Students enter their name
- Select Breakfast, Lunch, and/or Dinner
- Store meal preferences in MySQL
- Dashboard showing meal counts
- Start New Day option to reset counts with admin password

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MySQL

## Project Structure

```
Dinely/
├── Dinely-Backend/
└── Dinely-Frontend/
```

## How to Run

1. Start MySQL.
2. Configure `application.properties`.
3. Run the Spring Boot application.
4. Open `Dinely-Frontend/index.html`.
